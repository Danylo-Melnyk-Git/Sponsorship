# Данные

Эта папка описывает организацию данных, а не служит утверждённой базой кандидатов.

Для будущих локальных рабочих материалов зарезервированы data/private/ и data/raw/; они исключены из Git. Выгрузки в data/exports/ также исключены. Эти папки создаются при необходимости.

В репозиторий можно добавлять отдельно подготовленные синтетические или разрешённые обезличенные примеры. Реальные офферы, внутренние материалы брендов и контакты не добавлять в отслеживаемые файлы автоматически.
