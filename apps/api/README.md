# Серверный интерфейс

server.py обслуживает локальный MVP 0.3 на 127.0.0.1. Изменения проходят ResearchService с обязательной revision. Есть JSON API, фиксированные статические ресурсы и экспорт.

[API локального режима](../../docs/architecture/lokalnyy-mvp.md). Добавлен отдельный `hosted.py` с учётными записями, CSRF и серверными ролями; [развёртывание и точные ограничения](../../infra/README.md). Контейнерный и браузерный вход нового режима ещё требуют проверки.

## Исходная проектная рамка

Будущие операции с брифами, материалами, исследованиями, кандидатами, отчётами и решениями модерации.

Сервер связывает веб-интерфейс с хранением данных и фоновыми заданиями. Контракты и технология определяются на этапе подробной архитектуры.
