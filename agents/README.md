# Роли агентов

Обновление 2026-10-04: планировщик, поиск и аналитик получают [профиль партнёра и формата](../docs/product/profil-partnera-i-format.md) в `task`. Он помогает определить потребность до конкретных имён и не назначает людей, не запускает агентов, не утверждает цену или выбор.

С 2026-10-01 есть [исполняемый контракт ролей](workflow.json): CLI формирует контекст и проверяет импорт результата. Роли выполняются ассистентом через инструменты Codex. Автоматически запущенных работников приложения нет.

| ID | Работа | Результат |
| --- | --- | --- |
| planner | Бриф и направления поиска | Вопросы/план, изменения брифа для владельца |
| discovery | Широкий поиск и чтение | Источники, кандидаты, фактический журнал |
| dossier | Выбранный пул | Досье и события для проверки |
| analyst | Конкретные пакеты | Оценки, сценарии, экономика, вопросы |
| reviewer | Основания и противоречия | Проверенные исправления и пробелы |
| manager | Проработка условий | Коммерческие вопросы и материалы для людей |
| measurement | Исполнение и результат | Сверка, план/факт, причины расхождений |

Команды: python sponsor.py task research-ID ROLE --out data/private/task-v1.json; затем python sponsor.py apply-role --file data/private/result-v1.json. Формат — в [руководстве](../docs/product/rukovodstvo-mvp.md). Экспорт контекста не означает выполненный поиск. Фактический поиск discovery проверен на двух запросах Exa; [протокол](../tests/proverka-mvp-2026-10-01.md).

Роль не записывает ручной выбор, решение C-level, реальную сделку или приёмку. Нельзя назначить новый статус «проверено» от имени человека или снять подтверждённый блок. Сохранение неизменённого результата человеческой проверки допускается при дополнении других полей.

## Проектные роли методологии

Прежняя карта ответственности сохраняется ниже. Один ассистент может выполнять несколько ролей последовательно.

| Роль | Ответственность | Выход |
| --- | --- | --- |
| Координатор | Связать задачу с требованиями, собрать результаты | Согласованный документ и список пробелов |
| Исследователь источников | Изучить доступность и покрытие данных | Каталог источников с ограничениями |
| Исследователь рынка | Изучить категории, географии и стратегию поиска | Методика обнаружения кандидатов |
| Аналитик методологии | Определить метрики, скоринг и неопределённость | Объяснимые расчётные правила |
| Аналитик рисков | Определить события, доказательства и критерии | Методика оценки рисков |
| Аналитик пакетов | Исследовать форматы сотрудничества и цену | Правила пакетов и ценовых диапазонов |
| Архитектор веб-продукта | Связать сценарии, модули и данные | Требования к веб-приложению |
| Проверяющий | Проверить основания, противоречия и полноту | Замечания и результат проверки |

Использование ролей не требует отдельного агента на каждую. Делегирование выполняется по явному запросу пользователя. Все роли соблюдают корневой AGENTS.md.

Шаблон поручения: task-template.md.

По заданию 2026-09-30 добавлены [инструкции ролей для поиска и подбора](poisk-i-podbor.md), связанные с исследовательским CLI и форматом досье. Их можно выполнять последовательно одним ассистентом; отдельные агенты в этом прогоне не запускались.
