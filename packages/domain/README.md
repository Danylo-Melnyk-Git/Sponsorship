# Общая модель предметной области

Реализация MVP 0.3: models.py — валидация; store.py — транзакции и история; service.py — этапы и исходный план; agents.py — роли и импорт; reporting.py — отчёт; demo.py — синтетические сценарии.

[Архитектура](../../docs/architecture/lokalnyy-mvp.md). Балл, риск, покрытие и экономика разделены.

Дополнение 2026-10-03/05: `quality.py` — план измерения, оценки, полнота и запросы отделам; проверка измерения отдельно обозначает описательный план и заявленный сравнительный дизайн, не подтверждая причинность; `activation.py` — договорный реестр, остатки, зависимости и подтверждение назначения; `activation_catalog.json` — 16 пулов/48 шаблонов. [Руководство](../../docs/product/proverka-i-ispolnenie.md).

Единицы измерения, даты, валюты, источники и версии явны. Заполненность полей не подтверждает рыночную валидность модели.
