Обновление 2026-10-04: в `packages/runtime/providers.py` добавлены адаптеры OpenAI Responses, Anthropic Messages и Exa Search. [Ключи, ограничения и статус](../../infra/README.md). Платные запросы не проверялись; запуск из веб-интерфейса не подключён. Старый чатовый путь ниже сохраняется.

legacy.py подключает прежний поисковый прототип: план и точный импорт семи публичных досье с исходными датами. Неизвестные цены не подставляются. Сетевых вызовов в адаптере нет: фактический поиск выполняется через Codex с импортом результата роли.

## Исходная проектная рамка

Будущие адаптеры источников и загрузки материалов. Каждый адаптер должен возвращать данные вместе с происхождением, датой, ограничениями и доступной информацией о затратах.

Список поставщиков, способы доступа и поддерживаемые форматы утверждаются после исследования источников.
