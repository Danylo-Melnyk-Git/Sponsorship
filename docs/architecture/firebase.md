# Подключение Firestore

Дата: 2026-11-13. Реализовано и проверено на реальном проекте `sponsoradar-1580e`.

База `(default)`, Standard, регион `eur3 (Europe)`, тариф Spark. Создана в production mode с закрытыми клиентскими правилами. Python обращается через существующий сервисный аккаунт; IAM определяет его доступ. Ключ находится только в игнорируемом `secrets/firebase-service-account.json` и не передаётся браузеру.

## Запуск

Зависимости: `.venv-server/Scripts/python.exe -m pip install -r requirements-firebase.txt`.

Запуск: `./scripts/start-firebase.ps1`. Адрес: `http://127.0.0.1:8177`. Если политика PowerShell запрещает скрипты, задать `GOOGLE_APPLICATION_CREDENTIALS` равным абсолютному пути к локальному ключу и выполнить `.venv-server/Scripts/python.exe sponsor.py --database firestore://sponsoradar-1580e serve --port 8177`.

Для CLI использовать тот же ключ окружения и `--database firestore://sponsoradar-1580e`. Для защищённого ASGI-режима — `SPONSOR_DATABASE=firestore://sponsoradar-1580e` и доступный серверу ключ. Развёртывание ASGI с Firestore не выполнялось. Обычный запуск без выбора Firestore продолжает открывать SQLite. Существующие исследования SQLite в облако не переносились.

## Поведение и ограничения

- Коллекция `sponsorship_research`, у каждого исследования подколлекция `history`.
- Создание документа и первого снимка атомарно; обновление состояния и истории выполняется транзакцией с проверкой revision.
- Данные исследования сохраняются JSON-строкой для сохранения типов и прежнего контракта. Предел JSON — 900 000 байт; для больших исследований потребуется отдельная схема хранения.
- Авторизация пользователей и очередь заданий остаются прежними. Подключён Firestore; Firebase Authentication и публичное развёртывание этим изменением не реализованы.
- Локальный веб-сервер слушает только loopback.

## Проверка

`scripts/check-firebase.py` выполняет сетевой тест с синтетическим исследованием. Проверены создание через ResearchService, чтение, изменение, список, история, снимок, конфликт revision и отмена изменения при исключении. QA-документ оставлен для просмотра; повторный запуск создаёт новый. Результат: `data/qa/firebase-live.json`.

Дополнительно проверены HTTP API списка и карточки, загрузка синтетической записи браузером (HTTP 200, без ошибок консоли), анонимный запрос к Firestore (403). Общий набор: 193 теста, 8 пропущено из-за отсутствия необязательных зависимостей в системном Python; отдельно 6 тестов защищённого сервера прошли в `.venv-server`. JavaScript и проверка исследовательских артефактов прошли. `scripts/verify.ps1` заблокирован политикой PowerShell; его три команды выполнены отдельно.

Mini-PC QA и визуальная приёмка владельцем не проводились; GitHub, main и публичный деплой не затрагивались.
