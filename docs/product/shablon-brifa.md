## Проверка достаточности перед углублённым сравнением

1. Известны бренд/продукт, задача, аудитория и география, период и бюджет сотрудничества вместе с его периодом. Если один из пунктов отсутствует, записать конкретный уточняющий вопрос; исследование может остаться разведочным, но полноценную сравнимую оценку не обещать.
2. Названы первичный результат и предполагаемый способ его наблюдения. Если владелец их ещё не выбрал, показать варианты из [контракта решения](kontrakt-resheniya.md) как гипотезы для подтверждения.
3. Для аудита есть версия оффера; каждое условие отделено от внешней проверки и расчёта. Отсутствующие права, стоимость активации и метрики оставить неизвестными.
4. Фиксируются автор/дата изменения брифа, подтверждённые поля, допущения и открытые вопросы. Изменение цели, периода или бюджета создаёт новую версию сравнения.

**Итог уточнения:** «достаточно для следующего шага / возможен только предварительный разбор / требуется ответ владельца» с причинами. Численные пороги достаточности ещё не установлены.
