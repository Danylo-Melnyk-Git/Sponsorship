# Шаблон плана активации партнёра

Версия шаблона: 0.1 от 2026-10-01. Скопировать в закрытый рабочий файл для конкретной кампании. Все поля в угловых скобках требуют заполнения; строки-примеры не являются задачами, назначениями или подтверждёнными условиями.

| Поле | Значение |
| --- | --- |
| ID и название партнёрства | <ID / название> |
