# Веб-приложение

Согласовано: доступ к продукту через браузер. Ниже — предлагаемый каркас экранов, требующий детализации.

| Экран | Основное действие |
| --- | --- |
| Исследования | Создать запрос или вернуться к существующему |
| Бриф | Описать бренд, аудиторию, гео, задачу и бюджет; приложить материалы |
| Уточнения | Ответить на существенные вопросы и подтвердить допущения |
| Параметры исследования | Выбрать глубину, лимит расходов и приоритеты |
| Ход исследования | Видеть этап, затраты, пробелы и готовые части результата |
| Результаты | Сравнивать лучшие варианты и сегменты остальных кандидатов |
| Карточка кандидата | Изучать досье, доказательства, оценки, пакет и цену |
| Аудит предложения | Загрузить оффер, связать с брифом и получить заключение |
| Модерация | Проверить результат, внести замечания и выбрать кандидатов |
| Материалы для C-level | Получить краткое обоснование для согласования |

Обновление или закрытие страницы не должно отменять фоновое исследование. Статус и частичные результаты сохраняются на сервере. Для остановки предусматривается явное действие пользователя.

Показывать отдельно бюджет сотрудничества и расходы на исследование. Существенные выводы должны позволять открыть основания; факты, оценки и прогнозы визуально различаются.

Открыто: авторизация, число пользователей, доступ C-level непосредственно в приложение, формат передачи отчёта, язык интерфейса и мобильная версия. Наличие этапа согласования не означает, что C-level уже нужен отдельный кабинет.
