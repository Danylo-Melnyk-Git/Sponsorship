## Исходная проектная рамка

После разработки методологии проверять:

- Соответствие найденных кандидатов брифу и обоснованность исключений.
- Подтверждаемость существенных утверждений источниками.
- Воспроизводимость расчётов и реакцию на отсутствующие данные.
- Устойчивость ранжирования к изменению весов и допущений.
- Качество аудита офферов относительно экспертной проверки.
- Фактическую стоимость и покрытие режимов исследования.
- Полный веб-сценарий, сохранение прогресса и ручное согласование.

Для исследовательского прототипа поиска от 2026-09-30 добавлены [автоматические проверки](test_poisk_i_podbor.py) существенных ограничений: порог на одной платформе, пропуски/свежесть, бюджет/период/права, доказательства, дедупликация и бюджетные гипотезы.

Запуск из корня проекта:

~~~powershell
python -B -m unittest discover -s tests -p 'test_poisk_i_podbor.py' -v
~~~

Эти тесты проверяют техническую логику на синтетике. Целевые значения точности поиска, оценки цены и пригодности рекомендаций пока не определены; рыночная валидация ими не заменяется.
