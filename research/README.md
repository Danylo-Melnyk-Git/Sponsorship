Для каждого исследования создавать отдельную папку с понятным именем. Рекомендуемое содержание документа:

1. Вопрос и область применения.
2. Исходные требования и гипотезы.
3. Источники, даты и способ получения сведений.
4. Найденные факты и сравнение подходов.
5. Предлагаемая методика.
6. Ограничения и способы проверки.
7. Выводы для проекта и открытые решения.

Факты, авторские предложения и согласованные решения обозначаются отдельно. Исследовательские материалы не должны молча менять продуктовые требования.
